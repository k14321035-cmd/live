Introduction to Python & Setup

Beginner ~45 min No prerequisites 🧭 Systems Programming

What is Python?

Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum and first released in 1991. It emphasizes code readability and simplicity, using significant whitespace (indentation) to define code blocks instead of curly braces.

Python was designed with a philosophy that programming should be easy to read and enjoyable to write. Because of its clean syntax, Python is often recommended as the first programming language for beginners. At the same time, it is powerful enough to be used by large companies, researchers, and engineers.

Python is one of the most widely used programming languages in the world, powering everything from web backends and data science pipelines to AI research and automation scripts.

💡 Key Concept: Dynamic Typing
Unlike languages like C++ or Java, Python is dynamically typed. This means you don't need to declare if a variable is a number or a string; Python figures it out at runtime.

Why Python?

  • Easy to learn: Clean, English-like syntax lowers the barrier to entry.
  • Versatile: Web dev, data science, ML/AI, automation, scripting, games.
  • Huge ecosystem: 400,000+ packages on PyPI (Python Package Index).
  • Strong community: Massive documentation, tutorials, and forums.
  • Cross-platform: Runs on Windows, macOS, Linux identically.
  • Industry demand: Python developers are highly sought after in modern tech industries.

Where Python is Used

One of Python's greatest strengths is its flexibility. The same language can be used in many different industries and technologies.

  • Web Development: Frameworks like Django and Flask power websites and APIs.
  • Data Science: Libraries like Pandas and NumPy help analyze data efficiently.
  • Machine Learning & AI: TensorFlow and PyTorch are widely used in artificial intelligence.
  • Automation: Python can automate repetitive tasks like file management and scraping.
  • Cybersecurity: Ethical hackers use Python for scripting and security tools.
  • Game Development: Libraries like Pygame help create simple games.
🚀 Fun Fact
Companies such as Google, Netflix, Instagram, Spotify, and NASA use Python in production systems.

Installing Python

Download the latest version (3.x) from python.org. As of 2026, Python 3.12+ is recommended.

ℹ️ Version Note
Always install Python 3. Python 2 reached end-of-life in 2020 and should not be used for new projects.

Windows

Download the installer from python.org and check "Add Python to PATH" during installation. Verify in Command Prompt:

cmd / terminal 
python --version
# Expected: Python 3.12.x
⚠️ Troubleshooting PATH
If you get an error saying "python is not recognized", you likely forgot to check the "Add Python to PATH" box. You can fix this by rerunning the installer and choosing "Modify" or adding the path manually in System Environment Variables.

macOS / Linux

macOS comes with Python 2 by default. Use Homebrew to install Python 3:

terminal 
brew install python3
python3 --version

Choosing a Code Editor

Although Python code can be written in any text editor, using a modern code editor makes development significantly easier.

  • VS Code: Lightweight and beginner-friendly.
  • PyCharm: Powerful professional Python IDE.
  • Sublime Text: Fast and minimalistic.
  • Jupyter Notebook: Popular for data science and machine learning.

Your First Python Program

Open any text editor (VS Code is recommended) and create a file called hello.py:

hello.py 
# This is a comment — Python ignores it
print("Hello, World!")
print("Welcome to Python Mastery!")
Output
Hello, World!
Welcome to Python Mastery!

The print() function displays output to the screen. It is one of the first functions every Python developer learns because it helps visualize program behavior.

Running Python Programs

After saving your file, open the terminal in the same folder and execute the script:

terminal 
python hello.py

On some systems, especially Linux/macOS, you may need to use:

terminal 
python3 hello.py

Understanding Python Syntax Basics

Indentation is mandatory

Unlike C or Java, Python does not use { } to group code. It uses indentation (4 spaces per level by convention). Incorrect indentation will cause an IndentationError:

indentation.py 
if True:
    print("This is indented — it's inside the if block")
    print("So is this")
print("This is outside — runs regardless")

Most Python developers use 4 spaces for indentation. Mixing tabs and spaces can cause errors and should be avoided.

Case Sensitivity

Python is case-sensitive. This means that variables named Age, age, and AGE are treated as three entirely different variables.

case_test.py 
name = "Alice"
Name = "Bob"

print(name) # Prints Alice
print(Name) # Prints Bob

Comments

comments.py 
# Single-line comment — Python ignores this

"""
Multi-line string used as a docstring/comment block.
Often used to document functions and classes.
"""

x = 5  # Inline comment
✅ Best Practice
Write comments to explain why, not what. Code explains what it does; comments explain the reasoning.

Common Beginner Mistakes

  • Forgetting parentheses in print()
  • Incorrect indentation levels
  • Confusing uppercase and lowercase variable names
  • Saving files without the .py extension
  • Trying to run Python 2 code in Python 3

How Python Runs Code

Python is an interpreted language, but it doesn't run the source code directly. When you run python script.py, the following happens:

  • Compilation: The interpreter first compiles your human-readable .py code into Bytecode (a low-level, platform-independent set of instructions).
  • Caching: This bytecode is stored in .pyc files inside a folder called __pycache__ to make the program start faster next time.
  • Execution: The Python Virtual Machine (PVM) reads the bytecode and executes it on your hardware.
🧠 Important Insight
Because Python uses an interpreter, development is usually faster than compiled languages since you can test and modify code quickly.

Lecture 02 · Fundamentals

Variables & Data Types

Beginner ~50 min Requires: Lecture 01

Variables

A variable is a named reference to a value stored in memory. In Python, you create variables simply by assigning a value — no type declaration needed.

variables.py 
name = "Alice"
age = 25
height = 5.6
is_student = True

print(name, age, height, is_student)
Output
Alice 25 5.6 True

Multiple Assignment

Python allows you to assign values to multiple variables in a single line, which makes the code more concise:

multi_assign.py 
# Assigning different values to multiple variables
x, y, z = 10, 20, 30

# Assigning the same value to multiple variables
a = b = c = 100

print(x, y, z) # 10 20 30
print(a, b, c) # 100 100 100

Naming Rules

  • Must start with a letter or underscore (_)
  • Can contain letters, numbers, underscores — no spaces or special chars
  • Case-sensitive: Name ≠ name
  • Cannot be a Python keyword (if, for, class, etc.)
✅ Convention
Use snake_case for variables and functions: user_name, total_price. Use UPPER_CASE for constants: MAX_SIZE = 100.

Core Data Types

Type Example Description
int 42, -7, 0 Whole numbers (unlimited size)
float 3.14, -0.5 Decimal / floating point numbers
str "hello", 'world' Text (sequence of characters)
bool True, False Boolean (logical True/False)
NoneType None Represents the absence of a value

Integers

integers.py 
x = 42
y = -100
big = 1_000_000   # underscores for readability
binary = 0b1010   # binary literal → 10
hexval = 0xFF    # hexadecimal → 255

print(type(x))   # <class 'int'>
print(big)        # 1000000

Floats

floats.py 
pi = 3.14159
sci = 1.5e10     # scientific notation: 15000000000.0
neg = -2.7

print(type(pi))  # <class 'float'>

# Floating point precision caveat:
print(0.1 + 0.2)   # 0.30000000000000004 (IEEE 754)
⚠️ Float Precision
Floats have limited precision due to binary representation. For exact decimal arithmetic (e.g., money), use Python's decimal module.

Strings

strings.py 
s1 = "Hello, World!"
s2 = 'Single quotes work too'
s3 = """Triple-quoted strings
span multiple lines"""

# Escape sequences
s4 = "Line 1\nLine 2"     # \n = newline
s5 = "Tab\there"         # \t = tab
s6 = "Quote: \"hi\""      # \" = literal quote

# f-strings (Python 3.6+) — the preferred way
name = "Bob"
age = 30
msg = f"My name is {name} and I am {age} years old"
print(msg)
Output
My name is Bob and I am 30 years old

String Indexing & Slicing

Strings are sequences of characters. You can access individual characters using indices (starting at 0):

indexing.py 
word = "Python"

print(word[0])   # 'P' (First character)
print(word[2])   # 't' (Third character)
print(word[-1])  # 'n' (Last character)

# Slicing: [start : stop : step]
print(word[0:2])  # 'Py' (Index 0 up to, but not including, 2)
print(word[2:])    # 'thon' (From index 2 to the end)
print(word[::-1])   # 'nohtyP' (Reverses the string)

Booleans

booleans.py 
t = True
f = False

print(type(t))   # <class 'bool'>
print(True + True)  # 2 — bools are ints (True=1, False=0)

# Truthiness — these evaluate as False:
# 0, 0.0, "", [], {}, None
print(bool(0))    # False
print(bool(""))   # False
print(bool(42))   # True

Type Conversion

conversion.py 
# Explicit conversion (casting)
x = int("42")        # str → int: 42
y = float("3.14")    # str → float: 3.14
z = str(100)          # int → str: "100"
b = bool(1)           # int → bool: True

# Getting user input (always returns str)
name = input("Enter your name: ")
age  = int(input("Enter your age: "))  # must cast!
print(f"Hello {name}, you are {age}")

Implicit Type Conversion

Python automatically converts one data type to another when it makes sense to avoid data loss. This is called Implicit Conversion.

implicit.py 
num_int = 10    # int
num_float = 1.5  # float

result = num_int + num_float 
print(result)       # 11.5
print(type(result)) # <class 'float'> (Python promotes int to float)

Dynamic Typing & type()

Python is dynamically typed — the same variable can hold different types over its lifetime:

dynamic.py 
x = 10
print(type(x))   # <class 'int'>
x = "hello"
print(type(x))   # <class 'str'>
x = [1, 2, 3]
print(type(x))   # <class 'list'>

⚖️ Python vs Static Typing

Python (Dynamic)

  • ✅ Flexible and rapid development
  • ✅ No type declarations needed
  • ✅ Easier for beginners
  • ⚠️ Runtime type errors
  • ⚠️ Less IDE assistance

Static Languages (C++, Java, TypeScript)

  • ✅ Compile-time error checking
  • ✅ Better IDE support
  • ✅ Self-documenting code
  • ⚠️ More verbose
  • ⚠️ Slower development

Want to learn static typing? Try TypeScript for a gentle introduction!

Lecture 03 · Fundamentals

Operators & Expressions

Beginner ~45 min Requires: Lecture 02

What Are Operators?

Operators are symbols or keywords that perform operations on values and variables. Operators are used in almost every Python program because they allow us to calculate values, compare data, and make logical decisions.

operators_intro.py 
x = 10
y = 5

print(x + y)   # Arithmetic operator
print(x > y)   # Comparison operator
print(x == y)  # Equality operator

Python provides several categories of operators including arithmetic, comparison, logical, assignment, identity, and membership operators.

Expressions in Python

An expression is a combination of values, variables, and operators that produces a result after evaluation.

expressions.py 
result = (5 + 3) * 2

print(result)   # 16

Expressions can be simple or complex. Python evaluates expressions according to operator precedence rules.

Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations such as addition, subtraction, multiplication, and division.

arithmetic.py 
a, b = 17, 5

print(a + b)    # Addition:       22
print(a - b)    # Subtraction:    12
print(a * b)    # Multiplication: 85
print(a / b)    # Division:       3.4   (always float!)
print(a // b)   # Floor division: 3     (truncates decimal)
print(a % b)    # Modulo:         2     (remainder)
print(a ** b)   # Exponentiation: 1419857

The modulo operator % is commonly used to determine whether a number is even or odd.

even_odd.py 
number = 14

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")

Comparison Operators

Comparison operators compare two values and always return a boolean value: True or False.

comparison.py 
x = 10
print(x == 10)   # Equal:              True
print(x != 5)    # Not equal:          True
print(x > 8)     # Greater than:       True
print(x < 8)     # Less than:          False
print(x >= 10)   # Greater or equal:   True
print(x <= 9)    # Less or equal:      False

# Chained comparisons (Pythonic)
age = 20
print(18 <= age <= 65)

Comparison operators are commonly used with conditional statements such as if statements and loops.

Logical Operators

Logical operators combine multiple conditions together.

logical.py 
a = True
b = False

print(a and b)   # False — both must be True
print(a or b)    # True  — at least one True
print(not a)     # False — flips the boolean
logical_example.py 
username = "admin"
password = "1234"

if username == "admin" and password == "1234":
    print("Login successful")
else:
    print("Invalid credentials")

Assignment Operators

Assignment operators are used to assign values to variables and update existing values.

assignment.py 
x = 10
x += 5    # x = x + 5  → 15
x -= 3    # x = x - 3  → 12
x *= 2    # x = x * 2  → 24
x //= 4   # x = x // 4 → 6
x **= 2   # x = x ** 2 → 36

print(x)

These shorthand assignment operators make code shorter and easier to read.

Identity & Membership Operators

Identity operators compare memory locations, while membership operators check whether a value exists inside a sequence.

identity.py 
# Identity: is / is not
x = [1, 2, 3]
y = x
z = [1, 2, 3]

print(x is y)
print(x is z)
print(x == z)

# Membership: in / not in
fruits = ["apple", "banana", "cherry"]

print("banana" in fruits)
print("grape" not in fruits)

Operator Precedence

Python follows a specific order when evaluating expressions. Parentheses have the highest priority because they make expressions more readable and explicit.

precedence.py 
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
print(2 ** 3 ** 2)    # 512

Lecture 04 · Fundamentals

Control Flow: if / elif / else

Beginner ~50 min Requires: Lecture 03

What is Control Flow?

Control flow determines the order in which code executes in a program. Normally, Python runs code from top to bottom. However, conditional statements allow programs to make decisions and execute different blocks of code depending on conditions.

control_flow_intro.py 
weather = "rainy"

if weather == "rainy":
    print("Take an umbrella.")

print("Have a great day!")
Output
Take an umbrella.
Have a great day!

The if Statement

The if statement executes a block of code only when a condition is True.

if_basic.py 
temperature = 35

if temperature > 30:
    print("It's hot outside!")
    print("Stay hydrated.")
Output
It's hot outside!
Stay hydrated.

Notice the indentation inside the if block. Python uses indentation to determine which statements belong to the condition.

Using Boolean Conditions

Conditional statements often use comparison and logical operators to evaluate expressions.

boolean_conditions.py 
is_logged_in = True

if is_logged_in:
    print("Welcome back!")

if / else

The else block executes when the condition inside the if statement is False.

if_else.py 
age = 16

if age >= 18:
    print("You can vote.")
else:
    years_left = 18 - age
    print(f"You need to wait {years_left} more years.")
Output
You need to wait 2 more years.

Multiple Conditions with elif

The elif statement allows you to check multiple conditions one after another.

traffic_light.py 
light = "yellow"

if light == "green":
    print("Go")
elif light == "yellow":
    print("Slow down")
else:
    print("Stop")
Output
Slow down

if / elif / else

This structure is useful when there are many possible outcomes.

grades.py 
score = 78

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Score: {score} → Grade: {grade}")
Output
Score: 78 → Grade: C

Nested if Statements

You can place an if statement inside another if statement. This is called nesting.

nested.py 
username = "admin"
password = "secret123"

if username == "admin":
    if password == "secret123":
        print("Access granted!")
    else:
        print("Wrong password.")
else:
    print("Unknown user.")
Output
Access granted!

Combining Conditions

Logical operators such as and, or, and not are commonly used inside conditional statements.

logical_conditions.py 
age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("You may enter.")
else:
    print("Entry denied.")
Output
You may enter.

Ternary (Conditional Expression)

A ternary expression is a short one-line version of an if/else statement.

ternary.py 
age = 20

status = "adult" if age >= 18 else "minor"

print(status)
Output
adult

match / case (Python 3.10+)

Python introduced structural pattern matching in version 3.10. It works similarly to switch/case statements in other programming languages.

match.py 
command = "quit"

match command:
    case "start":
        print("Starting...")
    case "stop" | "quit":
        print("Stopping.")
    case _:
        print("Unknown command")
Output
Stopping.

Common Beginner Mistakes

Beginners often forget colons : after conditions or use incorrect indentation. Python relies heavily on indentation to structure code properly.

mistakes.py 
# Incorrect
# if age > 18
# print("Adult")

# Correct
if age > 18:
    print("Adult")

Lecture 05 · Fundamentals

Loops: for & while

Beginner ~55 min Requires: Lecture 04

What Are Loops?

Loops allow programs to repeat actions multiple times without rewriting the same code again and again. Loops are extremely important in programming because they automate repetitive tasks efficiently.

loop_intro.py 
for i in range(3):
    print("Learning Python loops!")
Output
Learning Python loops!
Learning Python loops!
Learning Python loops!

The for Loop

Python's for loop iterates over any iterable such as lists, strings, tuples, or ranges.

for_basic.py 
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(f"I like {fruit}")

# Iterating through a string
for char in "Python":
    print(char, end="-")
Output
I like apple
I like banana
I like cherry
P-y-t-h-o-n-

Looping Through Lists

Loops are commonly used to process items inside lists one by one.

list_loop.py 
numbers = [2, 4, 6, 8]

for number in numbers:
    print(number * 2)

range()

The range() function generates a sequence of numbers and is commonly used with loops.

range_demo.py 
# range(stop)
for i in range(5):
    print(i, end=" ")

# range(start, stop)
for i in range(1, 6):
    print(i, end=" ")

# range(start, stop, step)
for i in range(0, 20, 5):
    print(i, end=" ")

# Counting backwards
for i in range(10, 0, -1):
    print(i, end=" ")

Nested Loops

A loop inside another loop is called a nested loop. Nested loops are useful for working with tables, patterns, and matrices.

nested_loops.py 
for row in range(3):
    for col in range(3):
        print("*", end=" ")
    print()
Output
* * *
* * *
* * *

enumerate() and zip()

enumerate() provides both the index and value during iteration, while zip() combines multiple iterables together.

enumerate_zip.py 
# enumerate gives index + value
animals = ["cat", "dog", "bird"]

for i, animal in enumerate(animals, start=1):
    print(f"{i}. {animal}")

# zip iterates multiple lists simultaneously
names = ["Alice", "Bob", "Carol"]
scores = [95, 87, 92]

for name, score in zip(names, scores):
    print(f"{name}: {score}")

The while Loop

The while loop continues executing as long as its condition remains True.

while_basic.py 
count = 0

while count < 5:
    print(f"Count: {count}")
    count += 1

# Interactive while loop
while True:
    answer = input("Say 'quit' to exit: ")

    if answer == "quit":
        break

    print(f"You typed: {answer}")

Infinite Loops

An infinite loop never stops running unless interrupted manually or terminated using a statement like break.

infinite_loop.py 
# Be careful with infinite loops!

while True:
    print("This runs forever")
    break   # remove this to create a real infinite loop

break, continue, pass

These statements control loop behavior.

loop_control.py 
# break — exits the loop immediately
for i in range(10):
    if i == 5:
        break

    print(i, end=" ")

# continue — skips current iteration
for i in range(10):
    if i % 2 == 0:
        continue

    print(i, end=" ")

# pass — placeholder statement
for i in range(3):
    pass

Loop else Clause

Python loops can include an else block that executes only if the loop finishes normally without a break.

loop_else.py 
for i in range(5):
    print(i)
else:
    print("Loop completed successfully")

List Comprehensions (Preview)

List comprehensions provide a short and elegant way to create lists using loops.

comprehension.py 
# Standard way
squares = []

for i in range(1, 6):
    squares.append(i ** 2)

# List comprehension
squares = [i ** 2 for i in range(1, 6)]

print(squares)

# With filtering
evens = [x for x in range(20) if x % 2 == 0]

print(evens)

Common Beginner Mistakes

Beginners often forget to update loop variables in while loops, which may cause infinite loops. Another common mistake is incorrect indentation.

mistakes.py 
# Incorrect — infinite loop
# count = 0
# while count < 5:
#     print(count)

# Correct
count = 0

while count < 5:
    print(count)
    count += 1

Functions

Beginner ~60 min Requires: Lecture 05

What are Functions?

Functions are reusable blocks of code that perform a specific task. Instead of writing the same logic multiple times, you can place it inside a function and call it whenever needed.

why_functions.py 
# Without functions
print("Welcome, Alice!")
print("Welcome, Bob!")
print("Welcome, Carol!")

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner    = owner
        self._balance = balance   # _ = convention: "private"

    @property
    def balance(self):
        return self._balance

    @balance.setter
    def balance(self, amount):
        if amount < 0:
            raise ValueError("Balance cannot be negative")
        self._balance = amount

    def deposit(self, amount):
        self._balance += amount

    def withdraw(self, amount):
        if amount > self._balance:
            raise ValueError("Insufficient funds")
        self._balance -= amount

            f"Cannot withdraw {amount}; balance is {balance}"

task.py 
from datetime import datetime
import uuid

class Task:
    """Represents a single task."""

    def __init__(self, title, priority="medium"):
        self.id        = str(uuid.uuid4())[:8]
        self.title     = title
        self.priority  = priority
        self.done      = False
        self.created   = datetime.now().isoformat()

    def complete(self):
        self.done = True

    def to_dict(self):
        return vars(self)

    @classmethod
    def from_dict(cls, data):
        t = cls(data["title"], data["priority"])
        t.id      = data["id"]
        t.done    = data["done"]
        t.created = data["created"]
        return t

    def __str__(self):
        status = "✓" if self.done else "○"
        return f"[{status}] {self.id} | {self.title} ({self.priority})"


class TaskManager:
    """Manages a collection of tasks."""

    def __init__(self):
        self.tasks = []

    def add(self, title, priority="medium"):
        task = Task(title, priority)
        self.tasks.append(task)
        return task

    def complete(self, task_id):
        task = self._find(task_id)
        if task:
            task.complete()
            return task
        raise ValueError(f"Task {task_id} not found")

    def delete(self, task_id):
        task = self._find(task_id)
        if task:
            self.tasks.remove(task)
        else:
            raise ValueError(f"Task {task_id} not found")

    def filter(self, status="all"):
        if status == "done":
            return [t for t in self.tasks if t.done]
        elif status == "pending":
            return [t for t in self.tasks if not t.done]
        return self.tasks

    def _find(self, task_id):
        return next((t for t in self.tasks if t.id == task_id), None)

storage.py — JSON Persistence

storage.py 
import json
from pathlib import Path
from task import Task

FILE = Path("tasks.json")

def load():
    if not FILE.exists():
        return []
    with FILE.open() as f:
        return [Task.from_dict(d) for d in json.load(f)]

def save(tasks):
    with FILE.open("w") as f:
        json.dump([t.to_dict() for t in tasks], f, indent=2)

main.py — CLI Entry Point

main.py 
from task import TaskManager
import storage

def show_menu():
    print("\n── Task Manager ──────────────")
    print("  1. Add task")
    print("  2. List tasks")
    print("  3. Complete task")
    print("  4. Delete task")
    print("  5. Quit")
    print("──────────────────────────────")

def main():
    mgr = TaskManager()
    mgr.tasks = storage.load()

    while True:
        show_menu()
        choice = input("Choice: ").strip()

        if choice == "1":
            title    = input("Task title: ")
            priority = input("Priority (low/medium/high): ") or "medium"
            task = mgr.add(title, priority)
            print(f"Added: {task}")

        elif choice == "2":
            filt = input("Filter (all/pending/done): ") or "all"
            tasks = mgr.filter(filt)
            if not tasks:
                print("No tasks found.")
            else:
                for t in tasks:
                    print(" ", t)

        elif choice == "3":
            tid = input("Task ID to complete: ")
            try:
                t = mgr.complete(tid)
                print(f"Completed: {t}")
            except ValueError as e:
                print(f"Error: {e}")

        elif choice == "4":
            tid = input("Task ID to delete: ")
            try:
                mgr.delete(tid)
                print("Deleted.")
            except ValueError as e:
                print(f"Error: {e}")

        elif choice == "5":
            storage.save(mgr.tasks)
            print("Goodbye! Tasks saved.")
            break

        storage.save(mgr.tasks)   # auto-save after every action


if __name__ == "__main__":
    main()

Step 3 — Working with Templates

app.py 
from flask import Flask, render_template

Why Templates? Templates separate backend logic from frontend design, making projects cleaner and easier to manage.

Step 4 — Adding a Database

Most applications need permanent data storage. We'll use SQLite because it is lightweight and built into Python.

database.py 
import sqlite3

connection = sqlite3.connect("database.db")
cursor = connection.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL
)
""")

connection.commit()
connection.close()

This creates a database file and a table for storing tasks.

Step 5 — Adding Tasks

Users should be able to submit tasks through a form.

index.html 
<form method="POST">
    <input type="text" name="task" placeholder="Enter task">
    <button type="submit">Add</button>
</form>

Update Flask logic to handle form submissions.

app.py 
from flask import request

@app.route("/", methods=["GET", "POST"])
def home():

    if request.method == "POST":
        task = request.form["task"]
        print(task)

    return render_template("index.html")

Template Engine: Flask uses Jinja2 templating. The syntax {{ }} prints values, while {% %} handles logic like loops and conditions.
