Lecture 01 · Fundamentals

Introduction to Shell Scripting

Beginner ~45 min

What is Shell Scripting?

Shell scripting (primarily Bash) allows you to automate tasks, manage systems, and build powerful DevOps pipelines using the command line.

Why Master Shell?

  • Essential for Linux servers, CI/CD, and cloud operations
  • Fast automation of repetitive tasks
  • Powerful combination with tools like `awk`, `sed`, `grep`

Your First Script

hello.sh 
#!/bin/bash
echo "Hello, Shell Mastery!"
echo "Today is $(date)"

Lecture 02 · Fundamentals

Variables & Data Types

Beginner~45 min

Shell Variables

In shell scripting, variables store data for later use. Unlike compiled languages, shell variables are untyped — they store everything as strings by default. No spaces around = when assigning.

variables.sh
#!/bin/bash
name="Ahmed"
age=25
pi=3.14159
echo "Name: $name, Age: $age, PI: $pi"

Special Variables

VariableMeaning
$0Script name
$1..$9Positional arguments
$#Number of arguments
$@All arguments (separate)
$?Exit code of last command
$$Current script PID

Command Substitution

cmd_sub.sh
#!/bin/bash
today=$(date +%Y-%m-%d)
files=$(ls | wc -l)
echo "Date: $today | Files: $files"

Readonly & Export

scope.sh
#!/bin/bash
readonly PI=3.14159
export PATH="/custom/bin:$PATH"
local_var="only in this script"

Lecture 03 · Fundamentals

Operators & Expressions

Beginner~45 min

Arithmetic

math.sh
#!/bin/bash
a=10; b=3
echo $((a + b))   # 13
echo $((a * b))   # 30
echo $((a % b))   # 1
echo $((a ** b))  # 1000
((a++)); echo $a  # 11

Numeric Comparisons

compare.sh
#!/bin/bash
x=10; y=20
[[ $x -eq $y ]]  # equal
[[ $x -ne $y ]]  # not equal
[[ $x -lt $y ]]  # less than
[[ $x -gt $y ]]  # greater than
[[ $x -le $y ]]  # less or equal
[[ $x -ge $y ]]  # greater or equal

String & Logical Operators

logical.sh
#!/bin/bash
[[ "$a" = "$b" ]]   # equal
[[ -z "$a" ]]       # is empty
[[ -n "$a" ]]       # is not empty
[[ $age -ge 18 && $lic == true ]]  # AND
[[ $a -lt 0 || $b -gt 100 ]]      # OR

File Test Operators

Lecture 04 · Fundamentals

Control Flow

Beginner~45 min

If-Elif-Else

ifelse.sh
#!/bin/bash
read -p "Enter age: " age
if [[ $age -lt 13 ]]; then
    echo "Child"
elif [[ $age -lt 20 ]]; then
    echo "Teen"
else
    echo "Adult"
fi

Case Statement

case.sh
#!/bin/bash
read -p "Pick (start|stop|restart): " cmd
case $cmd in
    start)   echo "Starting...";;
    stop)    echo "Stopping...";;
    restart) echo "Restarting...";;
    *)       echo "Unknown command";;
esac

Menu-Driven Script

menu.sh
#!/bin/bash
echo "1) Date  2) Uptime  3) Disk  4) Exit"
read -p "Choice: " c
case $c in
    1) date;;  2) uptime;;
    3) df -h;; 4) exit;;
    *) echo "Invalid";;
esac

Exit Codes

$? holds the exit code of the last command. 0 = success, non-zero = failure.

exit.sh
#!/bin/bash
grep "error" app.log
if [[ $? -eq 0 ]]; then echo "Errors found"; fi
# Shorthand:
mkdir /tmp/dir && echo "OK" || echo "FAIL"
Practice

Build a menu with options: (1) Show users, (2) Show memory, (3) Ping google.com, (4) Exit.

Lecture 05 · Fundamentals

Loops

Beginner~45 min

For Loops

forloop.sh
#!/bin/bash
for fruit in apple banana mango; do echo "$fruit"; done
for ((i=1; i<=5; i++)); do echo "Count: $i"; done
for file in *.txt; do echo "Found: $file"; done

While Loop

while.sh
#!/bin/bash
count=1
while [[ $count -le 5 ]]; do echo "Iter $count"; ((count++)); done
# Read file line by line
while IFS= read -r line; do echo "$line"; done < /etc/hosts

Until Loop

Runs until condition becomes true (opposite of while):

until.sh
#!/bin/bash
n=1; until [[ $n -gt 5 ]]; do echo "$n"; ((n++)); done

Break & Continue

break.sh
#!/bin/bash
for i in {1..10}; do
    [[ $i -eq 3 ]] && continue
    [[ $i -eq 8 ]] && break
    echo "$i"
done  # Output: 1 2 4 5 6 7

Practical: Batch Rename

rename.sh
#!/bin/bash
c=1; for f in *.jpg; do mv "$f" "img_$(printf "%03d" $c).jpg"; ((c++)); done
echo "Renamed $((c-1)) files."

Print the multiplication table (1-10) for a number the user enters.

Lecture 06 · Core Concepts

Functions & Scripting

Intermediate~45 min

Defining Functions

func.sh
#!/bin/bash
greet() { local name=$1; echo "Hello, $name!"; }
greet "Ahmed"
add() { echo $(($1 + $2)); }
sum=$(add 5 7); echo "Sum: $sum"  # 12

Local Variables

Always use local inside functions to avoid side effects:

local.sh
#!/bin/bash
g="global"
demo() { local l="local"; g="changed"; echo "$l $g"; }
demo; echo "$g"  # "changed"

Function Libraries

lib.sh
#!/bin/bash
log() { echo "[$(date)] $*"; }
die() { echo "FATAL: $*" >&2; exit 1; }
main.sh
#!/bin/bash
source ./lib.sh
log "Starting..."; die "Disk full"

Error Handling

safe.sh
#!/bin/bash
delete() {
    local f=$1
    [[ ! -f "$f" ]] && { echo "Not found: $f" >&2; return 1; }
    rm "$f" && echo "Deleted: $f"
}
delete "/tmp/test.txt" || exit 1

Lecture 07 · Core Concepts

Arrays & String Manipulation

Intermediate~45 min

Indexed Arrays

arrays.sh
#!/bin/bash
arr=("a" "b" "c" "d")
echo "${arr[0]}"          # a
echo "${arr[@]}"          # all elements
echo "${#arr[@]}"         # count: 4
arr+=("e")                # append
for v in "${arr[@]}"; do echo "$v"; done

Associative Arrays

dict.sh
#!/bin/bash
declare -A user
user[name]="Ahmed"; user[age]=25
echo "${user[name]}"
for k in "${!user[@]}"; do echo "$k=${user[$k]}"; done

String Operations

strings.sh
#!/bin/bash
s="Hello World"
echo "${#s}"           # 11 (length)
echo "${s^^}"          # HELLO WORLD
echo "${s,,}"          # hello world
echo "${s:6:5}"        # World (substring)
echo "${s/World/Shell}" # Hello Shell
path="/a/b/c.txt"
echo "${path##*/}"     # c.txt (basename)
echo "${path%/*}"      # /a/b (dirname)

Practical: CSV Parser

csv.sh
#!/bin/bash
while IFS=',' read -r name age city; do
    echo "$name ($age) from $city"
done < data.csv

Process Management & Signals

Advanced~45 min

Background Processes

bg.sh
#!/bin/bash
sleep 30 &
pid=$!
echo "Job PID: $pid"
kill -0 $pid 2>/dev/null && echo "Running"
wait $pid; echo "Done (exit: $?)"

Trapping Signals

trap.sh
#!/bin/bash
cleanup() { echo "Interrupted!"; rm -f /tmp/lock; exit 1; }
trap cleanup SIGINT SIGTERM
touch /tmp/lock
while true; do echo "Working... $(date)"; sleep 2; done

Common Signals

Signal#Meaning
SIGINT2Ctrl+C interrupt
SIGTERM15Terminate (default kill)
SIGKILL9Force kill (cannot trap)
SIGHUP1Terminal closed

Parallel Processing

parallel.sh
#!/bin/bash
proc() { echo "Processing $1..."; sleep 2; echo "$1 done."; }
for f in a.txt b.txt c.txt; do proc "$f" & done
wait; echo "All done!"

Daemon Script

daemon.sh
#!/bin/bash
PIDFILE="/tmp/myd.pid"
case $1 in
  start) echo $$ > $PIDFILE; trap "rm $PIDFILE" EXIT
         while true; do echo "run..."; sleep 10; done & ;;
  stop)  [[ -f $PIDFILE ]] && kill $(cat $PIDFILE) && rm $PIDFILE ;;
  *)     echo "Usage: $0 start|stop" ;;
esac

Lecture 10 · Advanced

Regular Expressions & grep

Advanced~45 min

grep Essentials

grep.sh
#!/bin/bash
grep "error" app.log           # basic
grep -i "error" app.log        # case-insensitive
grep -n "error" app.log        # line numbers
grep -c "error" app.log        # count
grep -v "debug" app.log        # invert
grep -r "TODO" ./src/          # recursive
grep -C 3 "error" app.log      # context

Regex Patterns

regex.sh
#!/bin/bash
grep "^ERROR" app.log          # starts with
grep "done$" app.log           # ends with
grep "[Ee]rror" app.log        # char class
grep "[0-9]" app.log           # any digit
grep -E "(err|warn)" app.log   # alternation
grep -E "[0-9]{1,3}\.[0-9]{1,3}" file  # IP pattern

sed — Stream Editor

sed.sh
#!/bin/bash
sed 's/old/new/' file.txt      # replace first
sed 's/old/new/g' file.txt     # replace all
sed '/pattern/d' file.txt      # delete lines
sed -n '5,10p' file.txt        # print lines 5-10
sed -i 's/foo/bar/g' file.txt  # in-place

awk — Pattern Scanner

awk.sh
#!/bin/bash
awk '{print $1, $3}' data.txt              # columns
awk '$3 > 100' data.txt                    # filter
awk '{sum+=$2} END {print sum}' data.txt   # sum
awk -F',' '{print $2}' data.csv            # custom delimiter

Lecture 12 · Advanced

Capstone Project: Automation Toolkit

Advanced~60 min

Project Overview

Build a comprehensive System Automation Toolkit — a single script with a menu that performs common sysadmin tasks. This consolidates everything you've learned.

Features to Implement

  • System health check (CPU, memory, disk)
  • Backup specified directories with timestamps
  • Log analyzer (find errors, count by severity)
  • User management (add/remove/list users)
  • Service status checker

Starter Template

autotool.sh
#!/bin/bash
set -euo pipefail
source ./lib/utils.sh
show_menu() {
    echo "=== AutoTool ==="
    echo "1) Health Check  3) Log Analyzer"
    echo "2) Backup        4) User Mgmt"
    echo "5) Service Check 6) Exit"
}
health_check() {
    echo "CPU: $(top -bn1 | grep 'Cpu' | awk '{print $2}')%"
    echo "Mem: $(free -m | awk '/Mem/{printf "%.1f%%", $3/$2*100}')"
    echo "Disk: $(df -h / | tail -1 | awk '{print $5}')"
}
backup() {
    local src=$1 dst="/backup/$(date +%Y%m%d_%H%M%S)"
    mkdir -p "$dst" && cp -r "$src" "$dst"
    echo "Backed up to $dst"
}
while true; do
    show_menu
    read -p "Choice: " c
    case $c in
        1) health_check;;  2) read -p "Dir: " d; backup "$d";;
        3) ./log_analyzer.sh;;  4) ./user_mgmt.sh;;
        5) systemctl status nginx;;  6) exit;;
    esac
done

Bonus Challenges

  • Add email alerts for critical conditions
  • Schedule the health check via cron
  • Generate HTML reports instead of plain text
  • Add a web dashboard using a simple HTTP server
