Introduction to JavaScript

Beginner ~30 min No prerequisites

What is JavaScript?

JavaScript (JS) is a high-level, interpreted, multi-paradigm programming language used to create interactive and dynamic web applications.

It was created in 1995 by Brendan Eich at Netscape and has since become one of the most widely used programming languages in the world.

JavaScript powers:

  • Interactive websites
  • Web applications
  • Server-side applications using Node.js
  • Desktop apps with Electron
  • Mobile apps using frameworks like React Native
  • Games, APIs, and automation tools

Brief History of JavaScript

  • 1995 – First appeared as “LiveScript” in Netscape Navigator.
  • 1996 – Renamed to JavaScript.
  • 1997 – Standardised as ECMAScript 1.
  • 2009 – Node.js brought JavaScript to the server.
  • 2015 – ES6 (ES2015) introduced major modern features.
  • Today – JavaScript continues evolving with yearly ECMAScript updates.
✅ Why learn JavaScript?
JavaScript runs almost everywhere — browsers, servers, mobile devices, desktop applications, and even IoT devices. Learning JavaScript opens the door to frontend, backend, and full-stack development.

Why JavaScript is Important

  • Universal: Supported by all modern browsers.
  • Fast: Modern engines like V8 optimize performance heavily.
  • Flexible: Supports procedural, functional, and object-oriented programming.
  • Huge Ecosystem: Millions of packages available through npm.
  • Beginner Friendly: Easy syntax compared to many programming languages.

JavaScript vs Java

Despite the similar names, JavaScript and Java are completely different languages.

JavaScript Java
Runs mainly in browsers and Node.js Runs on the JVM
Dynamically typed Statically typed
Prototype-based Class-based
Mainly used for web development Used for enterprise, Android, backend systems
⚠️ Common Confusion
JavaScript is not a simplified version of Java. They are different languages designed for different purposes.

How JavaScript Executes

  • JavaScript engines like V8, SpiderMonkey, and JavaScriptCore parse the source code.
  • The engine converts source code into machine instructions.
  • Modern engines use JIT (Just-In-Time) compilation for speed.
  • The event loop handles asynchronous operations like timers and network requests.

Variables & Data Types

Beginner ~45 min Requires: Lecture 02

Introduction

Variables are used to store data in JavaScript programs.

Every application — from simple calculators to large web applications — relies heavily on variables and data types.

In this lecture, you will learn:

  • How to declare variables
  • The difference between var, let, and const
  • JavaScript primitive data types
  • Type checking with typeof

✅ Important
JavaScript is a dynamically typed language, meaning variables can hold different types of values during runtime.

Declaring Variables

JavaScript provides three main keywords for declaring variables:

  • var – function scoped, older syntax.
  • let – block scoped, recommended for mutable values.
  • const – block scoped, recommended for fixed values.
variables.js 
var legacy = 10;

let mutable = 20;

const immutable = 30;

console.log(legacy, mutable, immutable);
▶ Output
10 20 30

Understanding Scope

Scope determines where a variable can be accessed.

Keyword Scope Type
var Function Scope
let Block Scope
const Block Scope

Block Scope Example

scope.js 
if (true) {

    let message = 'Inside block';

    console.log(message);
}

// console.log(message);
// ReferenceError

Hoisting

JavaScript moves variable declarations to the top of their scope during compilation. This behavior is called hoisting.

Example with var

hoisting.js 
console.log(count);

var count = 5;
▶ Output
undefined
⚠️ Best Practice
Prefer using let and const instead of var in modern JavaScript development.

Primitive Types

JavaScript has seven primitive data types.

  • Number – numeric values such as 42 or 3.14
  • BigInt – very large integers
  • String – textual data
  • Boolean – true or false
  • Symbol – unique identifiers
  • undefined – variable declared but not assigned
  • null – intentional empty value

Operators & Expressions

Introduction

Operators are symbols that perform operations on values and variables.

Expressions are combinations of values, variables, and operators that produce a result.

JavaScript provides many different kinds of operators for arithmetic, comparisons, logic, assignment, and more.

✅ Why operators matter
Operators are used everywhere in programming — calculations, conditions, loops, user input, animations, games, APIs, and web applications.

Comparison Operators

Comparison operators compare values and return either true or false.

Lecture 05 · Foundations

Control Flow

Beginner ~45 min Requires: Lecture 04

Introduction to Control Flow

Control flow determines the order in which JavaScript executes statements in a program. By using conditions and loops, programs can make decisions, repeat tasks, and react to different situations dynamically.

💡 Real-world example
A login system uses control flow to check whether a username and password are correct before allowing access to an application.

If / else if / else

The if statement executes code only when a condition evaluates to true. Additional conditions can be checked using else if.

ifelse.js 
let score = 85;

if (score >= 90) {
    console.log("Grade A");
} else if (score >= 80) {
    console.log("Grade B");
} else {
    console.log("Needs improvement");
}

Truthy and Falsy Values

JavaScript automatically converts some values into true or false when used inside conditions.

  • Falsy values: false, 0, "", null, undefined, NaN
  • Everything else is generally considered truthy.
truthy_falsy.js 
let username = "";

if (username) {
    console.log("Welcome");
} else {
    console.log("Please enter a username");
}

Ternary Operator

The ternary operator provides a compact way to write simple conditional expressions.

ternary.js 
let age = 20;

let message = (age >= 18)
    ? "Adult"
    : "Minor";

console.log(message);

Switch Statement

The switch statement is useful when comparing one value against many possible cases.

switch.js 
let day = 'Monday';

switch (day) {
    case 'Monday':
        console.log('Start of the week');
        break;

    case 'Friday':
        console.log('Almost weekend');
        break;

    default:
        console.log('Just another day');
}
ℹ️ About break
Without break, execution continues into the next case. This behaviour is called fall-through.

Loops

Loops repeat a block of code until a condition becomes false. They are essential for processing arrays, generating patterns, and automating repetitive tasks.

for loop

The for loop is commonly used when the number of iterations is known.

for_loop.js 
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

while loop

The while loop repeats while a condition remains true.

while_loop.js 
let n = 1;

while (n <= 100) {
    console.log(n);
    n *= 2;
}

do…while loop

The do…while loop always executes at least once because the condition is checked after the loop body.

do_while.js 
let password;

do {
    password = prompt('Enter password (type 1234 to quit):');
} while (password !== '1234');

for...of and for...in

JavaScript provides special loops for arrays and objects.

  • for...of iterates over values.
  • for...in iterates over object keys.
special_loops.js 
const colors = ["red", "green", "blue"];

for (const color of colors) {
    console.log(color);
}

const user = {
    name: "Alice",
    age: 25
};

for (const key in user) {
    console.log(key, user[key]);
}

break & continue

  • break exits the nearest loop immediately.
  • continue skips the remainder of the current iteration.
break_continue.js 
for (let i = 1; i <= 10; i++) {

    if (i === 5) {
        continue;
    }

    if (i === 9) {
        break;
    }

    console.log(i);
}
✅ Best Practice
Avoid deeply nested conditions and loops when possible. Breaking logic into functions makes programs easier to read and maintain.

Common Beginner Mistakes

  • Using = instead of === inside conditions.
  • Creating infinite loops by forgetting to update loop variables.
  • Missing break statements inside switch.
  • Using loose equality (==) unexpectedly causing type coercion.

Functions

Intermediate ~55 min Requires: Lecture 05

Function Declarations & Expressions

Two common syntaxes:

  • Function Declaration (hoisted): function add(a, b) { … }
  • Function Expression (not hoisted): const add = function(a, b) { … };
functions.js 
function add(a, b) {
    return a + b;
}

const multiply = (a, b) => a * b;          // arrow function

console.log(add(3, 4));          // 7
console.log(multiply(5, 6));   // 30

Default Parameters & Rest Parameters

params.js 
function greet(name = 'World') {
    console.log(`Hello, \${name}!`);
}
greet();                // Hello, World!
greet('Alice');       // Hello, Alice!

function sumAll(...nums) {
    return nums.reduce((a, b) => a + b, 0);
}
console.log(sumAll(1, 2, 3)); // 6

Higher‑Order Functions & Callbacks

A function can receive another function as an argument or return one.

callback.js 
function fetchData(url, callback) {
    setTimeout(() => {
        const data = `Data from \${url}`;
        callback(data);
    }, 1000);
}

fetchData('/api', result => {
    console.log(result);
});
✅ Arrow functions vs regular functions
Arrow functions inherit this from the surrounding scope, while regular functions have their own this binding depending on how they are called.

Lecture 07 · Core Concepts

Objects & Prototypes

Intermediate ~55 min Requires: Lecture 06

Object Literals

Key/value pairs enclosed in {}. Property names can be strings or identifiers.

object.js 
const user = {
    name: "Bob",
    age: 30,
    isAdmin: true,
    greet() {
        console.log(`Hi, I'm \${this.name}`);
    }
};

console.log(user.name);    // Bob
user.greet();           // Hi, I’m Bob

Constructor Functions & Classes

Before ES6, objects were created via constructor functions and the new keyword. ES6 introduced class syntax which is syntactic sugar over the prototype chain.

class.js 
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        console.log(`\${this.name} says hello!`);
    }
}

const alice = new Person('Alice', 28);
alice.greet();    // Alice says hello!

Prototypal Inheritance

Every object has an internal [[Prototype]] (accessible via Object.getPrototypeOf or __proto__). Adding properties to the prototype makes them shared.

prototype.js 
function Animal(type) {
    this.type = type;
}

Animal.prototype.speak = function() {
    console.log(`\${this.type} makes a sound`);
};

const dog = new Animal('Dog');
dog.speak();   // Dog makes a sound
⚠️ Beware of shared mutable properties
If you put an object or array on a prototype, all instances will share the same reference, leading to unexpected side‑effects.

Array Basics

Arrays are ordered collections, created with [] or new Array().

array.js 
const numbers = [1, 2, 3, 4, 5];

Common Array Methods

  • push / pop – add/remove at end.
  • shift / unshift – add/remove at start.
  • forEach – iterate (no return).
  • map – transform to new array.
  • filter – select elements.
  • reduce – accumulate a single value.
  • find / findIndex – locate element.
higher_order.js 
const nums = [1, 2, 3, 4, 5];

// map – double each number
const doubled = nums.map(n => n * 2);
console.log(doubled);               // [2,4,6,8,10]

// filter – keep evens
const evens = nums.filter(n => n % 2 === 0);
console.log(evens);                // [2,4]

// reduce – sum
const sum = nums.reduce((acc, cur) => acc + cur, 0);
console.log(sum);                 // 15

Spread & Rest Operators

Use ... to expand or collect elements.

spread.js 
const a = [1, 2];
const b = [3, 4];
const combined = [...a, ...b];  // [1,2,3,4]

function logAll(...values) {
    console.log(values);
}
logAll(5, 6, 7);   // [5,6,7]

Lecture 09 · Core Concepts

Asynchronous JavaScript

Intermediate ~60 min Requires: Lecture 08

Callbacks

Functions passed to async APIs that run once the operation completes.

callback_async.js 
function delayedLog(msg, delay, cb) {
    setTimeout(() => {
        console.log(msg);
        if (cb) cb();
    }, delay);
}

delayedLog('First', 1000, () => {
    delayedLog('Second', 500);
});

Promises

Represent a value that may become available in the future. They can be chained and handle errors with catch.

promise.js 
function fetchNumber() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const n = 42;
            if (n) resolve(n);
            else reject('No number');
        }, 800);
    });
}

fetchNumber()
    .then(value => console.log('Got', value))
    .catch(err => console.error(err));

Async / Await

Syntactic sugar over promises; makes asynchronous code look synchronous.

async_await.js 
async getData() {
    try {
        const res = await fetch('https://api.github.com/users/octocat');
        const data = await res.json();
        console.log(data);
    } catch (e) {
        console.error(e);
    }
}

Basic UI Module (ui.js)

ui.js 
import { getTasks, addTask, toggleTask, deleteTask, setFilter } from './store.js';

const taskList = document.getElementById('task-list');
const newTaskInput = document.getElementById('new-task');
const filterButtons = document.querySelectorAll('.filters button');

function render() {
    const tasks = getTasks();
    taskList.innerHTML = '';
    tasks.forEach(t => {
        const li = document.createElement('li');
        li.className = t.done ? 'done' : '';
        li.innerHTML = `\${t.text}
            <button class="toggle">\${t.done ? '↩' : '✓'}</button>
            <button class="del">✕</button>`;

        li.querySelector('.toggle').addEventListener('click', () => {
            toggleTask(t.id);
            render();
        });
        li.querySelector('.del').addEventListener('click', () => {
            deleteTask(t.id);
            render();
        });

        taskList.appendChild(li);
    });
}

newTaskInput.addEventListener('keydown', e => {
    if (e.key === 'Enter' && newTaskInput.value.trim()) {
        addTask(newTaskInput.value.trim());
        newTaskInput.value = '';
        render();
    }
});

filterButtons.forEach(btn => {
    btn.addEventListener('click', () => {
        setFilter(btn.dataset.filter);
        render();
    });
});

render();

Store Module (store.js) – persists in localStorage

store.js 
let tasks = JSON.parse(localStorage.getItem('tasks')) || [];
let filter = 'all';

function save() {
    localStorage.setItem('tasks', JSON.stringify(tasks));
}

export function getTasks() {
    if (filter === 'active') return tasks.filter(t => !t.done);
    if (filter === 'completed') return tasks.filter(t => t.done);
    return tasks;
}

export function addTask(text) {
    const id = Date.now();
    tasks.push({id, text, done: false, createdAt: new Date()});
    save();
}

export function toggleTask(id) {
    const t = tasks.find(x => x.id === id);
    if (t) t.done = !t.done;
    save();
}

export function deleteTask(id) {
    tasks = tasks.filter(x => x.id !== id);
    save();
}

export function setFilter(mode) {
    filter = mode;
}
